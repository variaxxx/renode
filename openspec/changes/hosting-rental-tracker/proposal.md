## Why

Арендованные серверы распределены между провайдерами, поэтому даты продления, расходы и доступы легко потерять из виду. Нужен личный веб-сервис, который собирает эту информацию в одном месте и напоминает о действиях до окончания аренды.

## What Changes

- Добавить закрытую веб-админку для одного владельца без публичной регистрации.
- Оформить интерфейс на shadcn/ui с темной темой для всех экранов первой версии.
- Добавить каталог провайдеров и серверов с датами оплаты, окончания аренды и отмены, статусом и назначением.
- Добавить историю ручных платежей, обзор ближайших продлений и расходов.
- Добавить Telegram-уведомления о сроках и серверный воркер для их отправки.
- Добавить хранилище паролей провайдеров: шифрование и расшифровка в браузере по мастер-паролю, на сервере только шифротекст; предусмотреть резервный ключ восстановления.
- Отложить мониторинг доступности, автоматический вход в кабинеты провайдеров, импорт счетов и командный доступ.

## Capabilities

### New Capabilities

- `owner-access`: вход единственного владельца, защищенный доступ к админке и темная тема интерфейса.
- `rental-inventory`: учет провайдеров и серверов, их назначения, состояния и сроков аренды.
- `billing-reminders`: ручной учет платежей, обзор расходов и Telegram-напоминания.
- `credential-vault`: клиентское шифрование паролей провайдеров и восстановление доступа к ним.

### Modified Capabilities

Нет: в проекте пока отсутствуют действующие спецификации.

## Impact

Потребуются frontend на React с shadcn/ui, backend API и воркер на NestJS с Bun, Prisma ORM, PostgreSQL, ESLint и Prettier, а также Telegram-бот. Backend реализуется по соглашениям локального skill `nestjs-feature-architecture`. Репозиторий пока содержит только каркас OpenSpec; существующий код и API не затрагиваются.
