## Purpose

Позволяет владельцу вести структурированный каталог провайдеров и арендованных серверов, чтобы видеть назначение ресурсов и сроки важных действий.

## ADDED Requirements

### Requirement: Provider catalog
Система SHALL позволять владельцу создавать, просматривать, изменять и удалять провайдеров с названием, ссылкой на личный кабинет и необязательной заметкой.

#### Scenario: Add provider
- **WHEN** владелец сохраняет нового провайдера с названием
- **THEN** провайдер появляется в каталоге и становится доступен для привязки серверов

#### Scenario: Delete provider with servers
- **WHEN** владелец пытается удалить провайдера с привязанными серверами
- **THEN** система предотвращает удаление и объясняет, что сначала нужно перенести или удалить серверы

### Requirement: Server catalog
Система SHALL позволять владельцу создавать, просматривать, изменять, архивировать и удалять серверы, привязанные к провайдеру. Карточка сервера SHALL содержать название, назначение, статус, тариф, стоимость, валюту, период оплаты, дату следующей оплаты, дату окончания аренды, признак автопродления и необязательный срок отмены; IP, домен, проект, теги и заметка SHALL быть необязательными.

#### Scenario: Add rented server
- **WHEN** владелец сохраняет сервер с обязательными полями и существующим провайдером
- **THEN** сервер появляется в каталоге и учитывается в обзоре сроков и расходов

#### Scenario: Missing renewal date
- **WHEN** владелец сохраняет активный сервер без даты следующей оплаты
- **THEN** система отклоняет сохранение с указанием недостающего поля

#### Scenario: Archive server
- **WHEN** владелец архивирует сервер
- **THEN** история сервера сохраняется, а будущие напоминания и ожидаемые расходы по нему прекращаются

#### Scenario: Delete server with payment history
- **WHEN** владелец пытается удалить сервер с записанными платежами
- **THEN** система предотвращает удаление и предлагает архивировать сервер для сохранения истории

### Requirement: Find infrastructure
Система SHALL позволять искать серверы по названию и фильтровать их по провайдеру, статусу и проекту или тегу.

#### Scenario: Filter by provider
- **WHEN** владелец выбирает провайдера в фильтре
- **THEN** каталог показывает только его серверы
